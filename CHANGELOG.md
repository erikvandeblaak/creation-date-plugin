# Changelog

All notable changes to this plugin. The newest version is at the top.

## [1.2.0] - 2026-11-12

- Updates: PhpStorm now finds new versions through the plugin repository on GitHub.
- English texts, Dutch when the system language is Dutch.
- Works on PhpStorm 2026.2 and all newer versions.

## [1.1.0] - 2026-10-23

- Yellow balloon with the creation date and time when you hover over a file or folder in the Project view (Dutch only).
